***Challenge*** Data Analysis of survival in Breast Cancer patients using Kaplan-Meier curves and Cox mnodels with time-dependent variables.

***Focus*** Data cleaning and *feature engineering*; automation of data extraction, transformation and loading (ETL); Visualization with Matplotlib; Linear Regression and Cluster Analysis; *Notebook* discussion.

***Results*** Dashboard with key metrics (heart rate, distance, sleep) which allow data tracking with ease.

***Stack*** Python · pandas · Matplotlib · statsmodels · Sci-kit learn · Jupyter
