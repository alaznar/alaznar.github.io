***Challenge*** Classification of patients into 3 different groups: Diabetic, Prediabetic or Non-diabetic

***Focus*** Data exploration and scaling; ML models deployment: k-NN, Naïve Bayes, SVMs, ANN, Classification trees, Random Forest; Model assessment for slightly imbalanced data: accuracy, recall, precision and F1-score; Confusion Matrix analysis

***Results*** Deployment of 9 models: Random Forest with 500 trees performed best with ~ 98% accuracy and 0.98 F1-score. Moderate imbalanced data jeopardized some models performance.

***Stack*** Python · Matplotlib · keras · tensorFlow · sci-kit learn
